# homebrew-pokemonpet

[PokemonPet](https://github.com/kang-yujeong/PokemonPet) 설치용 Homebrew tap.

## 설치

```bash
brew tap kang-yujeong/pokemonpet
brew install --cask pokemonpet
```

> **처음 실행할 때 "확인되지 않은 개발자" 경고가 뜨면?**
> 정식 애플 개발자 인증서로 서명된 앱이 아니라서 macOS Gatekeeper가 한 번 막아요.
> Finder에서 PokemonPet 앱을 **우클릭 → 열기**를 한 번 해주면 그다음부터는 정상적으로 실행돼요.

## 사용법

**시작**
- 앱을 실행하면 바탕화면에 포켓몬이 나타나요 (처음 실행하면 1세대 스타터 한 마리를 자동으로 줘요).
- 포켓몬을 클릭하면 조작 모드가 켜져서 방향키로 움직일 수 있어요. 마우스로 드래그해서 옮길 수도 있어요.
- 포켓몬 옆 🎒 버튼을 누르면 트레이너 가방이 열려요.

**야생 포켓몬 만나기**
- 일정 시간마다 바탕화면에 야생 포켓몬이 나타나요 (등장 간격은 설정에서 조절 가능).
- 내 포켓몬을 조작해서 부딪히거나, 야생 포켓몬을 직접 클릭하면 자동으로 다가가서 배틀이 시작돼요.

**배틀**
- 싸운다 / 가방 / 포켓몬 / 도망간다 중에서 선택해요.
- 기술마다 위력·타입·PP가 있고, 상태이상(마비/화상/독/수면/얼음)과 특성(정전기·부유 등 일부는 실제로 배틀에 영향)이 실제 게임처럼 반영돼요.
- 이기면 포획을 시도할 수 있어요 — 몬스터볼을 던져서 확률대로 성공/실패가 갈리고, 실패해도 도망만 안 가면 남은 몬스터볼로 계속 재도전할 수 있어요.
- 마스터볼(도감 완성 보상으로만 얻을 수 있어요)을 쓰면 100% 확정으로 잡혀요.

**트레이너 가방 탭**
- **뽑기**: 몬볼을 써서 랜덤 포켓몬을 얻어요. 1회 뽑기 또는 10+1 묶음 뽑기 가능.
- **도감함**: 잡은 포켓몬 전체 목록과 도감 설명문을 볼 수 있고, 완성도(구간별/세대별/테마 세트별)에 따라 보상을 받아요.
- **내 포켓몬**: 파티(최대 6마리)와 보관함. 각 포켓몬의 ⋯ 메뉴에서 진화의 돌·이상한사탕·기술머신을 쓸 수 있어요.
- **상점**: 코인으로 회복약, 상태이상 치료제, 진화의 돌, 몬볼 등을 살 수 있어요.
- **설정**: 포켓몬 크기, 야생 포켓몬 등장 간격, 바탕화면에만 보이기 옵션을 바꿀 수 있어요.

**재화**
- 🎫 몬볼 — 뽑기 전용. 하루에 1개씩 자동으로 쌓이고, 상점에서 200코인에 살 수도 있어요.
- 몬스터볼 — 포획 전용. 배틀 승리로 획득해요 (상대 등급이 높을수록 더 많이).
- 🪙 코인 — 상점 화폐. 역시 배틀 승리로 획득해요.

## 업데이트

```bash
brew upgrade --cask pokemonpet
```

## 삭제

```bash
brew uninstall --cask pokemonpet
brew untap kang-yujeong/pokemonpet
```
